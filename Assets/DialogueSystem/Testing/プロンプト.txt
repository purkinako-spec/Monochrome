【前提条件と禁止事項】
・指定されたインターフェースのメソッドのみを完全に一致するシグネチャで実装してください。
・`OnDestroy` などで `UnregisterHandler` を呼び出さないでください（システムに存在しません）。
・出力はC#のコードブロックのみとし、余計な解説は絶対に省いてください。
・ファイル先頭には必ず以下の using を含めてください。
using System;
using System.Collections;
using UnityEngine;
using Runtime.Dialogue;
using Runtime.Dialogue.Core;
using Runtime.Dialogue.Branching;

【実装ルール：演出コマンド (IDialogueCommandHandler) の場合】
1. [属性付与] クラス直上に必ず `[HandlerInfo("説明", "使い方: [コマンド名:引数=値]")]` を記述すること。
2. [必須実装] `IDialogueCommandHandler` を実装し、以下のプロパティとメソッドを一言一句違わず定義すること。
   - `public string TargetCommandName { get; }` （例: `public string TargetCommandName => "コマンド名";`）
   - `public void Execute(DialogueCommand command, Action onComplete)`
   - `public void ForceComplete(DialogueCommand command)`
3. [登録処理] `Start()` 内で `DialogueEventDispatcher.Instance.RegisterHandler(this);` のみを実行すること（解除処理は書かない）。
4. [引数取得] 引数は `command.GetString("key", default)`、`command.GetFloat("key", default)`、`command.GetInt("key", default)` を用いること。
5. [完了通知] `Execute` 内の処理（コルーチン等）が終わったら、最後に必ず `onComplete?.Invoke();` を呼ぶこと。
6. [スキップ] `ForceComplete` 内では、進行中のコルーチンを止め（`StopAllCoroutines()`等）、最終状態を即座に適用すること（`onComplete` は呼ばない）。

【実装ルール：分岐ハンドラー (IDialogueBranchHandler) の場合】
1. [属性付与] クラス直上に必ず `[HandlerInfo("説明", "使い方")]` を記述すること。
2. [必須実装] `IDialogueBranchHandler` を実装し、以下のプロパティとメソッドを一言一句違わず定義すること。
   - `public int Priority { get; }` （例: `public int Priority => 50;`）
   - `public bool TryHandleBranch(System.Collections.Generic.List<ChoiceData> choices, Action<string> onBranchDecided)`
3. [登録処理] `Start()` 内で `DialogueBranchDispatcher.Instance.RegisterHandler(this);` のみを実行すること（解除処理は書かない）。
4. [分岐判定] `TryHandleBranch` 内で `choices` を処理し、条件（`branchType` の一致など）を満たせば `onBranchDecided?.Invoke(遷移先ID);` を呼び `true` を返すこと。満たさなければ `false` を返すこと。
