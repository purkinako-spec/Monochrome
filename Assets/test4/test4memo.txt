. シーンへの配置方法

テクスチャの設定ができたら、描画する方法は大きく分けて3つあります。作りたいゲームの形式に合わせて選んでください。

① 【2Dゲーム】Sprite Renderer を使う（最も一般的）

2Dゲームを作る場合の標準的な方法です。
1. Hierarchy上で右クリック ＞ 2D Object ＞ Sprite を作成します。
2. 作成したオブジェクトの Sprite Renderer コンポーネントにある Sprite 欄に、先ほど設定したテクスチャをドラッグ＆ドロップします。

② 【3Dゲーム】マテリアルにテクスチャを貼る（HD-2Dや3Dドット絵風）

3D空間にドット絵を配置したい場合（『オクトパストラベラー』のような表現や、3Dモデルの表面をドット絵にする場合）に使用します。
1. Project ウィンドウで右クリック ＞ Create ＞ Material で新しいマテリアルを作ります。
2. マテリアルのインスペクターにある Base Map（または Albedo）の四角い枠に、ドット絵のテクスチャをドラッグ＆ドロップします。
3. 3Dのオブジェクト（CubeやPlaneなど）に、そのマテリアルをドラッグ＆ドロップして適用します。
	• ※2Dの板ポリゴンとして配置したい場合は、Sprite Renderer のままでも3D空間に配置可能です。

③ 【UI画面】Raw Image を使う（スクリプトからテクスチャを直接制御するなど）

UI（体力ゲージやメニュー画面）としてドット絵を出したい場合や、プログラム（Texture2D）で描いたドット絵をそのまま映したい場合に便利です。
1. Hierarchy上で右クリック ＞ UI ＞ Raw Image を作成します。
2. Raw Image コンポーネントの Texture 欄に、テクスチャをドラッグ＆ドロップします。
